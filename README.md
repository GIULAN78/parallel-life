# Parallel Life

**Live the life you didn't choose.**

Parallel Life is an open source simulation game where you create an avatar and live a parallel life in your own city or region: the life you might have had if you had made different choices. Past, present or imagined future.

## Idea

- Create an avatar and pick a turning point (studies, job, city, relationships).
- The simulation plays out the following years with events, choices and consequences.
- The world is built on real places, using open map data (OpenStreetMap).
- Everyone can contribute: new cities, events, stories and features.

## Roadmap

1. Text-based prototype: avatar, turning points, life simulation.
2. 2D map of a real city.
3. Shared multiplayer world, where parallel lives meet.
4. Optional 3D client.

## How to contribute

The core stays small. Cities, events and story packs are separate modules and data files (JSON), so anyone can add their own piece without breaking the others. Open an issue to propose an idea, or send a pull request.

## Business model

The code is free. The hosted service starts free, with a daily amount of credits, and extra credits can be bought. Anyone can also run their own copy.
